# MAGO CREATION 10周年 LP（モック）

長坂真護 全国100ヶ所巡回個展 — 特設ホームページ（たたき台）

## 開き方

`index.html` をブラウザで開く（ダブルクリックで可）。

Live Server 利用時: `http://127.0.0.1:5500/index.html`（MAGO10TH フォルダをルートに開く）

## 構成

- プロンプト指定の8セクション（ヘッダー・ヒーロー・About・開催概要・新作・スケジュール・問い合わせ・フッター）
- 追加：**10年の年表**、**アートの向こう側（現地活動）**
- Tailwind CDN・1ファイル完結・レスポンシブ

## 画像素材

`images/` に [magogallery.online](https://magogallery.online/) 公式サイトの素材をモック用に保存しています。

- ヒーロー・About・活動・作品・ギャラリー等
- 公開前モックのため。本番公開前はクライアント確認・権利の最終確認を推奨
